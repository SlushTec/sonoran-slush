# SOP — HARD LAW (process core)

**Load order:** This file is **first** on every `init` / `reinit` for this repo.  
**Authority:** Overrides habit, chat length, and convenience.

**Also mandatory on boot:** `docs/OWNERS_PERSONALITY.md` (full) + `docs/init/PROFILE.md`.

**Note:** Full game-dev seat lenses live primarily in SlushTec/varp and SlushTec/ashcourt. This repo (physical brand + site) uses the process subset: anti-waste, sole git, one objective, FAST/Expert/Heavy, weekly rituals.

---

## 0. Identity

| Agent | Lane | MUST | MUST NOT |
|-------|------|------|----------|
| **Grok** | Lead / sole git / sole research / synthesis | Decide, batch, push, research→disseminate | Parallel-push |

Specialty seats idle until useful. No permanent parliament.

---

## 1. Resource / anti-waste (MANDATORY)

### MUST
1. Prefer project memory + `docs/init/` over re-fetching.  
2. Exploratory reads **≤5** before draft.  
3. **FAST** for ops, status, park, agenda.  
4. One **primary objective** per Owner message; park the rest.  
5. Git lock → stop.  
6. Stage exit = land.  
7. **Checkpoint:** append Useful/Waste row to tracker.  
8. **Monday evening:** recall week burn. **Week reset: Tuesday 12:30 MST.**

### MUST NOT
1. Owner as first discovery of fails.  
2. Re-litigate locks without Owner ask.  
3. Multi-stage on one `continue`.  
4. Push “should pass.”
