# Saved-design removal focus

A focused Remove button previously disappeared with its saved card, leaving keyboard focus on the document body. Saved designs now mirror the existing Bag focus strategy: keep the same remaining list index, fall back to the prior last item, and focus Explore the collection when the list becomes empty. This runs only after explicit saved-item removal, not on ordinary hydration or other state changes.

The storage operations, saved collection semantics, retention, confirmation policy and business metadata are unchanged. DOM first/middle/last and repeated-empty cases plus headless Edge keyboard Enter journeys at390/1280 verify behavior. Native pixels are not physical-device or manual assistive-technology qualification. No public deployment or real commerce involved. Original external red is retained outside the candidate.
