# Documentation map and precedence

Current platform decisions live in `architecture/`; customer and release requirements live in `requirements/`.
`business/SOURCE-REGISTER.md` identifies preserved source documents and open contradictions.
`delivery/` describes four work-agent lanes and reviewable acceptance criteria. `runbooks/` describes execution.

Existing product, pricing, FAQ, event, equipment, brand and owner documents are preserved unchanged as business references.
They may contain old Shopify instructions or stale/contradictory prices and promises. Those portions are not executable
configuration or a customer-facing knowledge base. Only approved, normalized public records may enter the catalog or retrieval.
The dated archive preserves every pre-reset document and the old site. Old agent initialization/work orders are superseded.
