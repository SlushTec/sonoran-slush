**Last updated:** 2026-08-11

## Service discount — 10% off

**Who qualifies**
- Verified **veterans**
- Verified **first responders** (police, fire, EMS, etc.)
- Verified **teachers** / educators

**Amount:** **10% off** the order (product subtotal)

**Scope:** Shop-wide — 3D crystal, surface engraving, boards, tumblers, smalls, bases, and listed add-ons (background, text) unless a future exclusion is noted.

**Verification**
- Customer must provide verification before the discount is applied (e.g. ID, professional credentials, or a trusted verification service such as ID.me / SheerID if enabled later).
- Until an automated app is live: manual code issued after verification (email / in-person / event).

**How it applies**
| Rule | Detail |
|------|--------|
| Base | 10% off product subtotal |
| Stacking | Does **not** stack with other % discounts unless explicitly allowed |
| Free shipping | Still based on **pre-discount** or **post-discount** cart rules — default: threshold checked on **post-discount** total (configure in Shopify) |
| Tax | AZ tax calculated on the discounted taxable amount |
| Events / on-site | Same 10% with ID check at the table |

**Shopify setup (when live)**
1. Create discount code group or automatic discount: *Veteran / First Responder / Teacher — 10%*
2. Prefer verification app (ID.me, SheerID, or similar) when volume justifies it
3. Until then: unique single-use or limited codes issued after manual verify

**Site copy (suggested)**
> **10% off for verified veterans, first responders, and teachers.**  
> Verify once — discount applied at checkout.
