# Website Plan — sonoranslush.net

## Goal

Replace the current Squarespace “under construction” placeholder with a clean, conversion-focused custom-order site that supports the photo → 3D crystal (and related) ordering experience.

## Platform Decision

**Shopify** (recommended and selected direction)

Reasons:
- Strong support for product configurators and photo upload flows
- Reliable payments, order management, and mobile experience
- Easy domain connection for `sonoranslush.net`
- Can look fully custom (AI store builder will not be used)
- Future-ready for brand merchandise (VARP / Ashcourt / studio items)

## Desired Ordering Experience (inspired by 3dcrystal reference)

1. Product / shape selection
2. Size options with clear pricing
3. Add-ons (light bases, wooden bases, keychains, custom inscription, etc.)
4. Photo upload
5. Customer details
6. Dynamic total → checkout

## Implementation Notes

- Use a clean, non-AI base theme and customize heavily
- Add a capable product options / file-upload app for the configurator experience
- Keep the design aligned with Tucson / desert / high-quality gift aesthetic
- Structure catalog so future SlushTec brand merchandise can be added as a separate collection without disrupting the custom gift flow

## Status

Planning complete. Shopify storefront configuration and theme work pending.
