## 3. Bulk rules

| Rule | Detail |
|------|--------|
| **Same design** | Bulk tiers assume one logo/text layout across the run |
| **Mixed names** | (e.g. each glass a different name) = single pricing or custom quote — setup time is higher |
| **Color fill** | Batched by color when possible; longer SLA always |
| **SERVICE10** | 10% vet / first responder / teacher applies to bulk subtotal unless a separate event contract is used |
| **Free shipping** | $75 threshold still applies online; large bulk may ship freight — quote |
| **Events / on-site** | Portable engraver jobs quoted separately (labor + blanks + time on site) |
| **100+** | Always quote — blank cost, packing, and cure capacity matter |

---

## 4. Site / Shopify setup notes

- Use **quantity breaks** on the product (Shopify native or volume-discount app) for 6 / 12 / 24 / 48  
- Or separate “Bulk / Event” inquiry form for 24+ and mixed personalization  
- Show **two columns** on product page: Engrave only | Color fill  
- When Color fill selected: show **+X business days** copy
