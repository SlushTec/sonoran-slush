## 0. Identity — not four identical agents

| Agent | Lane | MUST | MUST NOT |
|-------|------|------|----------|
| **Grok** | Lead / sole git / **sole research** / synthesis | Decide, batch, push, assign stages, research→disseminate | Parallel-push; seats doing research/git |

## 1. Resource / anti-waste (MANDATORY)

### MUST
1. Prefer project memory + `docs/init/` over re-fetching the same files.  
2. Exploratory reads **≤5** before draft (unless Owner deep-audit).  
3. **FAST** for ops, status, park, agenda.  
4. One **primary objective** per Owner message; park the rest.  
5. Git lock → stop.  
6. Stage exit = land or clear log — conversation ≠ utilization.  
7. **Checkpoint:** append Useful/Waste row to `docs/init/USEFUL-WASTE-TRACKER.md` (Owner need not see it).  
8. **Monday evening:** recall week burn from tracker. **Week reset: Tuesday 12:30 MST.**

### MUST NOT
1. Owner as first discovery of fails.  
2. Re-litigate locks without Owner ask.  
3. Parallel identical tool chains across seats.  
4. Multi-stage on one `continue`.  
5. Push “should pass.”  
6. Long restatements of laws already locked this session.  
7. Seats running outside research or git.
