# Sonoran Slush website (static)

Open `index.html` in a browser, or serve locally:

```bash
cd site
python3 -m http.server 8080
# visit http://localhost:8080
```

## Pages
- `index.html` — home
- `crystals.html` — 3D crystal catalog (emotional copy)
- `shop.html` — glass, wood, drinkware
- `events.html` — weddings, sports, graduation, any gathering
- `photo-guide.html` — what converts to crystal
- `faq.html` · `about.html` · `contact.html`

## Images
Lifestyle and blank photos under `images/`. Placeholders under `images/placeholders/` for SKUs still being shot.
